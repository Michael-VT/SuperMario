# 🍄 Супер Марио — версия DeepSeek

[English](README.md) | [Українська](README.UA.md) | **Русский** | [Deutsch](README.DE.md) | [Français](README.FR.md) | [Português](README.PT.md)

Экспериментальный платформер в стиле Super Mario, упакованный в **один HTML-файл**, созданный вместе с ИИ-чатом **DeepSeek**. Без фреймворков и сборки — просто откройте файл в браузере и играйте.

> 🤖 **Об эксперименте:** вся игра (HTML + CSS + JavaScript, ~1770 строк) сгенерирована в диалоге с DeepSeek и затем доработана. Проект опубликован как пример разработки игр с помощью ИИ. Полный лог переписки (`log.txt`) в репозиторий не входит.

## ▶️ Как играть

1. Скачайте или клонируйте этот репозиторий.
2. Откройте `SuperMarioDeepSeek.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).
3. Введите имя игрока — и вперёд!

Без сервера, без установки, без зависимостей.

## 🎮 Управление

| Действие | Клавиатура | Экранная кнопка |
|---|---|---|
| Старт / Пауза | `Пробел` | ▶ Старт / Пауза |
| Движение влево | `←` | ◀ Влево |
| Движение вправо | `→` | Вправо ▶ |
| Прыжок | `↑` | ⤒ Прыжок |
| Приседание (подлезть под препятствие) | `↓` | ⤓ Присесть |
| Перезапуск забега | `Esc` | ⟲ Рестарт |

Движение с инерцией: Марио разгоняется, пока держите направление, и сначала тормозит при смене направления — классическое ощущение.

## 🕹️ Игровой процесс

- Маршрут с препятствиями, ямами и бонусами генерируется в начале каждого забега.
- Собирайте бонусы: 🍒 вишенка — **1 очко**, 🍎 яблоко — **2 очка**, 🍯 мёд — **3 очка**.
- Пропустили бонус? Можно вернуться и взять его.
- Падение в яму стоит **1 из 3 жизней** ❤❤❤ — забег начинается заново. Потеряете все три — игра начинается сначала.
- Доберитесь до финиша и получите бонус **10 очков × оставшиеся жизни**.

## 🏆 Таблица результатов и история

- Текущий счёт показывается над таблицей лидеров.
- **Таблица топ-10** держится отсортированной, наибольший счёт вверху (номер места, имя, лучший счёт).
- Когда ваш счёт попадает в таблицу, запись с наименьшим счётом выбывает.
- **Последние 10 игр** показываются отдельным списком.
- Всё сохраняется в `localStorage` браузера, так что история останется и на следующий раз.

> Примечание: язык игрового интерфейса — русский.

## 🛠️ Технологии

- Один самодостаточный файл: HTML + CSS + JavaScript.
- Отрисовка на HTML5 `<canvas>` (900 × 400).
- Сохранение данных через `localStorage`.
- Спрайты бонусов нарисованы кодом — без графических файлов.
